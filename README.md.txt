# Local Government Constituency Website

A responsive website for a local government constituency, providing information about officials, projects, and community services.

## 🚀 Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Interactive Navigation**: Mobile-friendly hamburger menu
- **Project Showcase**: Display ongoing and completed municipal projects
- **Contact Form**: Allow residents to get in touch with officials
- **Scroll Animations**: Smooth reveal animations for better user experience
- **Accessibility**: ARIA labels and keyboard navigation support

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and structure
- **CSS3**: Custom properties, Flexbox, Grid, and responsive design
- **Vanilla JavaScript**: DOM manipulation, form validation, and animations
- **Intersection Observer API**: For scroll-based animations
